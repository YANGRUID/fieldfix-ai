# 90-second demo

**0–15s:** Open `http://localhost:5173`. Point out the active high-priority asset case, downtime clock, observations, and safety boundary—not a chat interface.

**15–35s:** Click **Run AI diagnosis**. Highlight ranked root causes with confidence and source chips. Note that no API key is required: the badge says offline demo.

**35–50s:** Open **Evidence**. Show the exact manual section and closed work orders that the diagnosis is allowed to cite.

**50–65s:** Open **Execution trace**. Show retrieval, structured reasoning, citation guard, latency, model mode, and estimated cost.

**65–90s:** Return to **AI diagnosis**, review next questions, conditional parts, and the safety-first repair plan. Check human approval, generate the report, and show the structured JSON ready for a service system.
